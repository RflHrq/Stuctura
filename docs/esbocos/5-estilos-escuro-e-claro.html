A — Noite de editor

Tudo escuro, como o editor de quem programa, com as cores do código servindo de cor da interface (azul, laranja, amarelo, verde). As caixas de papelão brilham nesse fundo. É a minha escolha — e o modo claro continua existindo para quem preferir.

B — Moldura de terminal

Topo escuro como uma janela de terminal, fundo de papel quadriculado no lugar do branco, rótulos escritos como comentário de código. Mais claro para ler por muito tempo; o botão principal fica laranja.

C — Terminal neon

Preto com verde e rosa neon, letra de código em tudo, desenhos só em contorno. É o mais “hacker”, e o mais cansativo para uma sessão longa; a arte colorida das caixas perde força.
