Ideia 1 de 6 · Pergunta 
void f(int n) { n = 99; printf("%d\n", n); }
int x = 1;
f(x);
printf("%d\n", x);
O que sai, nas duas linhas?
99 e 99: n é outro nome de x 99 e 1: são duas variáveis 99 e 99: f mexeu em x
Por quê?
A função ganha uma casa nova, só dela, para o parâmetro. A função recebe a variável original, não uma cópia.
